# 前端验收手册

> 这份文档回答一个问题：**「我改了这个，怎么证明它没坏？」**
> 与 `docs/PhaseD-*.md`（记录「改了什么」）互补 —— 那些文档会过时，这份不会。
> 适用对象：任何要改 `frontend/` 的人（含 AI agent）。

## 零、最高优先级的一条规则

> ⚠️ **新增任何检查项，必须先用一个故意的错误证明它会红。**

本项目已经吃过**四次**「假绿」的亏：

| # | 事件 | 表象 | 真相 |
|---|---|---|---|
| 1 | `smoke.mjs` 不登录 | 19 条路由全「✓」 | 路由守卫把每条都重定向到 `/login`，页面组件一行没执行 |
| 2 | `audit-css-tokens.mjs` 只打印不 exit | 输出「A 类 13 个」 | 退出码始终 0，CI 门禁形同虚设 |
| 3 | `_orphan-scan.py` 自写的正则 | 「0 个可疑项」 | 正则 `\|` 优先级 + 嵌套 `<template>` 截断 + 漏了图标全局注册，永远报不出问题 |
| 4 | `shot-workbench.mjs` 的宽度断言 | 注入 `display:block` 后仍全绿 | 块级包裹层**照样**把栏宽传给子元素，只有「等高」能发现 |

**绿而无检查能力，比红灯更危险** —— 它会让你放心地删掉真正有用的东西。

## 二、写验收脚本的六条硬约定

### 1. 造数必须「幂等且刷回已知状态」

命中已有标记行时**不能直接返回**，要把值 PUT 回标准值。
否则上一次跑崩留下的残留（比如验收自己写进去的探针变量）会让断言**碰巧通过** ——
**起点不确定的造数等于没有造数**。

`seed()` 必须放在 `try` **里面**，否则造数中途失败时 `finally` 的 `cleanup` 不执行，
标记数据永久残留（踩过一次，漏了三张表）。

### 2. 弹窗用「点取消并等它真的不可见」关闭，**不要用 `Escape`**

Element Plus 的 `el-dialog` 关闭后仍留在 DOM（`v-show`），而 `Escape` 在某些焦点位置不生效。
后果：弹窗没开时后续点击被遮罩拦掉，Playwright 报的却是「被 sidebar 拦截」—— 极难排查。

### 3. 数弹窗不要数 `.el-dialog`

Element Plus **懒渲染**：没打开过的弹窗**没有** `.el-dialog` 节点。
可靠做法是数常驻的 `.el-overlay.el-modal-dialog` / `.el-overlay.is-drawer`。

### 4. 样式要单独用「计算样式」验

非 scoped 的共享样式表漏掉 import 时，页面结构与**所有结构断言照样全绿**，
只有 `getComputedStyle` 算出来的值能发现。

范例：`shot-prompt-library.mjs` 断言 `.prompt-item` 的 `border-left === '3px'`。

⚠️ **边界**：CSS 一旦被任一组件 import 就是全局的，所以这类断言只能发现
「**整张表没被加载**」，发现不了「某个组件忘了 import」。

### 5. 页面滚动在内层 `.content` 容器，不是 `body`

`window.scrollTo` 无效，要滚 `.content`。

### 6. 面板类名同时是验收脚本的钩子

`.group-panel` / `.item-panel` / `.prompt-item` / `.prod-layout` / `.task-panel` 都被脚本依赖。
**拆组件时保留旧类名**，验收基线才能原样比对。

## 三、三个最容易踩的工程陷阱

### 3.1 `.vue` 的行尾**不统一**（CRLF 与 LF 混用）

- 手工编辑过的壳（`Knowledge` / `Keyword` / `IntentQuestion` / `Production` / `BrowserStudio` /
  `Layout.vue` / `router/index.js`）：**CRLF**
- D4–D6 用工具生成的新组件（如 `RunListPanel.vue`）：**LF**

**写批量替换脚本前必须先探测**：

```python
s = open(p, encoding='utf-8', newline='').read()
NL = '\r\n' if '\r\n' in s else '\n'
```

用 `text.split('\n')` 处理 CRLF 文件会让每行残留 `\r`，再全局 `\n → \r\n` 就变成 `\r\r\n`。
Vue 编译器报的却是 `(2:3) Element is missing end tag` —— **行号指向第 2 行，与真正的错误无关**。
改完用「裸 `\n` 计数必须为 0」验证。

### 3.2 模板拼接漏掉根 `</div>` 是同一个报错

定位手段：数 `<div` 与 `</div>` 的数量差。
另一种同源错误：`<template #slot>` 包装时**多加了一个 `</template>`**（脚本里 splice 和 close
两处各写了一次），同样报 `Element is missing end tag`。

### 3.3 Python `open(p, 'w')` 会先截断文件

```python
# ❌ src 读失败时 dst 已被清空
open(dst, 'w').write(open(src, encoding='utf-8', newline='').read())
```

正确写法：先读入内存，再写临时文件 + 原子替换。

```python
def write(p, s):
    tmp = p + '.tmp'
    open(tmp, 'w', encoding='utf-8', newline='').write(s)
    os.replace(tmp, p)
```

并且：**注入/还原脚本必须幂等**（本机命令可能被执行两次），备份放**仓库内**（`scripts/.d7bak/`），
别放 `/tmp`。

## 四、`_orphan-scan.py` 会查什么

拆走逻辑后壳里常见的五类残留：

1. 调用了已搬走函数的语句 → `ReferenceError`，且会让后续 `await` 全部不执行
2. 模板用了但没 import 的子组件
3. 只被搬走标记使用的死 CSS 规则
4. 渲染了跨组件类却没 import 共享样式表（**徽标静默变裸文字，截图看不出**）
5. 重复实现（同一个函数在两处各写一份）

⚠️ 它自己踩过三个「永远报不出问题」的假绿坑（正则 `|` 优先级、嵌套 `<template>` 截断、
漏了图标全局注册）—— **改它之后必须用故意注入的错误文件重验**。

## 五、`audit-css-tokens.mjs` 的口径

- **A 类（`var(--x)` 未定义且无 fallback）必须为 0** —— 这类声明会被浏览器**整条丢弃**，
  静默回退到继承色。**A 类 > 0 时脚本 exit 1**，已是 CI 门禁。
- 扫描器已排除两类**误报**：运行时 `:style` 注入的局部变量（`--rc` / `--dc` / `--pc` /
  `--cat-color`）、Element Plus 自有的 `--el-*`。
- **B 类（未定义但有 fallback）**是提示性的。目前的 2 个来自 `WorkbenchLayout`：
  `--wb-detail`（只有用到 `detail` 槽时才由组件写入）与 `--wb-min-height`（只有传了 `minHeight`
  prop 才写）。两者都**刻意**带 fallback，是条件变量，**不要为了清零去删 fallback** ——
  删了就变成 A 类，声明会被整条丢弃。
- **C 类（已定义未引用）是提示性的**：完整色阶（`--red-*` / `--amber-*` / `--emerald-*` 各 7 档）
  是**刻意保留**的设计系统资产，不要为了「清零」去删。

## 六、环境

- 后端启动：`cd backend && APP_NO_BROWSER=1 ./venv/Scripts/python.exe run.py`（端口 8765）
- 浏览器：`playwright-core` + 系统 Edge（`channel: 'msedge'`），**不需要下载 Chromium**
- 调试脚本必须放在 `frontend/scripts/` 下 —— `playwright-core` 按脚本所在位置解析模块，
  放 `/tmp` 会 `ERR_MODULE_NOT_FOUND`
- 本机 curl 走代理，回环请求需 `--noproxy '*'`
